# 사진대지 매크로 (한글)

한글(HWP) 문서의 표에 사진을 순서대로 자동으로 넣어주는 프로그램입니다.
표의 열 수와 캡션 행 유무를 스스로 감지하기 때문에, 양식이 바뀌어도 그대로 사용할 수 있습니다.

- 지원 형식: `.hwp`, `.hwpx`
- 필요 환경: Windows, 한글(HWP) 설치

---

## 1. 설치

### 방법 A. 실행파일로 쓰기 (권장)

[Releases](../../releases/latest) 에서 `hwp_image_macro.zip` 을 내려받아
압축을 풀고 `hwp_image_macro.exe` 를 실행합니다.
파이썬 설치가 필요 없습니다.

> 처음 실행할 때 "Windows의 PC 보호" 경고가 뜰 수 있습니다.
> **추가 정보 → 실행** 을 누르면 됩니다. 코드 서명이 없는 개인 제작 프로그램이라 뜨는 경고입니다.

### 방법 B. 소스로 실행하기

```bash
git clone https://github.com/chw0912/hwp_image_macro.git
cd hwp_image_macro
pip install -r requirements.txt
python hwp_photo_macro.py
```

## 2. 보안 모듈 등록 (한 번만)

등록하지 않으면 사진을 넣을 때마다 *"다른 프로그램이 문서에 접근하려고 합니다"* 팝업이 떠서
자동 삽입이 계속 멈춥니다. 한 번만 해두면 됩니다.

1. `FilePathCheckerModule.dll` 을 내려받아 원하는 폴더에 둡니다.
   (한컴 자동화 예제에 포함된 파일이며, 검색으로 구할 수 있습니다.)
2. `Win + R` → `regedit` 실행
3. `HKEY_CURRENT_USER\Software\HNC\HwpAutomation\Modules` 로 이동
   - 경로가 없으면 키를 직접 만듭니다.
4. 새 **문자열 값** 을 만들고
   - 이름: `FilePathChecker`
   - 값: dll 의 전체 경로 (예: `C:\hwp\FilePathCheckerModule.dll`)

등록하지 않아도 팝업을 매번 수동으로 눌러가며 쓸 수는 있습니다.

## 3. 사용법

1. **한글에서 사진대지 양식 문서를 엽니다.**
2. 프로그램을 실행하고 **[한글 연결]** 을 누릅니다.
   - 상단에 문서 이름이 초록색으로 뜨면 연결된 것입니다.
3. **[사진 추가]** 또는 **[폴더 추가]** 로 사진을 불러옵니다.
   - **[사진 추가]** 는 선택한 순서를 그대로 유지합니다. 정렬하지 않습니다.
   - **[폴더 추가]** 는 선택 순서가 없으므로 파일명 순으로 들어갑니다. (`IMG_2` 가 `IMG_10` 보다 앞)
   - 이름순으로 맞추고 싶으면 **[이름순 정렬]** 버튼을 누르면 됩니다.
   - 목록 오른쪽 화살표 버튼으로 순서를 바꿀 수 있습니다.
   - 캡션 칸을 **더블클릭**하면 사진 설명을 입력할 수 있습니다.
4. **한글에서 첫 번째 사진 칸을 클릭합니다.** (커서를 그 칸에 둡니다)
5. **[한번에 넣기]** 를 누르면 표가 끝날 때까지 순서대로 채웁니다.
   - 한 장씩 확인하며 넣고 싶으면 **[한 장 넣기]** 를 씁니다.

### 단축키

| 키 | 동작 |
|---|---|
| `Ctrl + Q` | 한 장 넣기 |
| `Ctrl + Shift + A` | 한번에 넣기 |

한글 창을 보고 있는 상태에서도 동작합니다.

### 사진이 표 칸보다 많을 때

넣기를 시작하기 전에 **칸이 몇 개 부족한지 미리 알려주고** 진행 여부를 묻습니다.
그대로 진행하면 칸이 찰 때까지만 채우고 멈추며, **들어가지 못한 사진은 목록에 그대로 남습니다.**

이어서 넣는 방법은 다음과 같습니다.

1. 한글에서 양식 페이지를 복사해 뒤에 붙여 넣습니다. (페이지 통째로 복사 → 붙여넣기)
2. 새로 생긴 표의 **첫 사진 칸을 클릭**합니다.
3. **[한번에 넣기]** 를 다시 누르면 남은 사진부터 이어집니다.

미리 확인하고 싶으면 사진을 담은 뒤 **[표 구조 확인]** 을 눌러보세요.
남은 칸 수와 넣을 사진 수를 비교해서 몇 장이 부족한지 알려줍니다.

### 표가 여러 페이지일 때

표가 끝나면 안내창이 뜨고 멈춥니다.
다음 페이지 표의 첫 사진 칸을 클릭하고 다시 **[한번에 넣기]** 를 누르면 남은 사진부터 이어집니다.

## 4. 옵션

| 옵션 | 설명 |
|---|---|
| **자동 감지** | 표를 훑어서 높이가 큰 칸은 사진 칸, 작은 칸은 캡션 칸으로 판단합니다. 열 수를 지정할 필요가 없습니다. |
| **사진 칸 최소 높이(mm)** | 자동 감지가 틀릴 때 직접 기준을 정합니다. `0` 이면 자동 계산. |
| **모든 칸에 사진 넣기** | 캡션 행이 없고 모든 칸이 사진인 표에 사용합니다. |
| **캡션 자동 입력** | 사진 아래 칸에 설명을 자동으로 적습니다. |
| **캡션 비면 파일명 사용** | 캡션을 입력하지 않은 사진은 파일명을 그대로 넣습니다. |
| **여백 (mm)** | 사진과 칸 테두리 사이 간격입니다. |
| **테두리** | 사진 둘레에 실선 테두리를 넣습니다. |

**[표 구조 확인]** 버튼을 누르면 현재 커서 위치 기준으로
몇 개의 칸이 사진 칸으로 판단됐는지 미리 볼 수 있습니다. 넣기 전에 확인해 보세요.

## 5. 자주 생기는 문제

**"커서가 표 안에 있지 않습니다"**
한글에서 사진을 넣을 칸을 먼저 클릭해 주세요. 프로그램 창이 아니라 한글 문서 쪽입니다.

**사진이 칸 밖으로 튀어나옴**
여백 값을 늘려보세요. 그래도 안 되면 이슈로 알려주세요. 한글 버전에 따라 크기 지정 방식이 다를 수 있습니다.

**캡션이 엉뚱한 칸에 들어감**
[표 구조 확인]으로 사진 칸 개수를 확인하고, 맞지 않으면 [사진 칸 최소 높이]를 직접 지정해 주세요.

**팝업이 계속 뜸**
위의 *보안 모듈 등록* 을 참고해 주세요.

## 6. 빌드 / 배포

### 자동 (GitHub Actions)

태그를 푸시하면 GitHub 의 Windows 환경에서 자동으로 빌드하고
릴리즈에 exe 와 zip 을 첨부합니다. 로컬에 Windows 가 없어도 됩니다.

```bash
git tag v1.0.0
git push origin v1.0.0
```

Actions 탭에서 진행 상황을 볼 수 있고, 3~5분 뒤 Releases 에 올라옵니다.

### 수동 (Windows 에서)

```bash
build.bat
```

`dist\hwp_image_macro.exe` 가 만들어집니다.
