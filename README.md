# 사진대지 매크로 (한글)

한글(HWP) 문서에서 **드래그로 선택한 표 칸**에 사진을 순서대로 자동 삽입하는 Windows 프로그램입니다.
칸 크기에 맞춰 자동으로 크기가 조정되며, 떨어져 있는 칸을 선택해도 그대로 처리됩니다.

- 지원 형식: `.hwp`, `.hwpx`
- 필요 환경: Windows, 한글(HWP) 설치

## 2. 사용법

1. **한글에서 사진을 넣을 문서를 엽니다.**
2. 프로그램을 실행하고 **[한글 연결]** 을 누릅니다.
   - 상단에 문서 이름이 초록색으로 뜨면 연결된 것입니다.
   - 다른 문서 이름이 뜨거나 연결이 안 되면 **[문서 열기]** 로 직접 지정합니다.
3. **[사진 추가]** 또는 **[폴더 추가]** 로 사진을 담습니다.
4. **한글에서 사진을 넣을 칸들을 드래그로 선택합니다.**
5. 프로그램의 **[선택한 칸에 넣기]** 를 누릅니다.

선택한 칸에 목록 순서대로 들어갑니다. 칸 하나에만 넣으려면 그 칸을 클릭하고 **[커서 칸에 한 장]** 을 누르면 됩니다.

### 선택에 대해

- **떨어진 칸도 됩니다.** 2행의 B~D, 5행의 C~E 처럼 나눠 선택해도 그대로 처리됩니다.
- **선택 순서가 아니라 표 순서대로** 채워집니다. 한글이 왼쪽 위에서 오른쪽 아래로 번호를 매기기 때문입니다.
- 프로그램 창을 클릭해도 한글의 선택은 유지됩니다.
- 넣고 나면 선택이 해제됩니다. 칸을 읽는 과정에서 소모되기 때문입니다.

### 사진 목록

- **[사진 추가]** 는 고른 순서를 그대로 유지합니다. 정렬하지 않습니다.
- **[폴더 추가]** 는 파일명 순으로 담습니다. (`IMG_2` 가 `IMG_10` 보다 앞)
- 오른쪽 화살표 버튼으로 순서를 바꿀 수 있습니다.
- 넣은 사진에는 `✔` 표시가 붙습니다. **[넣을 위치 처음으로]** 로 되돌릴 수 있습니다.

## 3. 옵션

| 옵션 | 설명 |
|---|---|
| **여백 주기 (mm)** | 사진과 칸 테두리 사이 간격입니다. 상·하·좌·우 각각 지정합니다. |
| **테두리 (mm)** | 사진 둘레에 실선 테두리를 넣습니다. |
| **비율 유지** | 켜면 원본 비율을 지켜 칸에 들어가는 최대 크기로 넣습니다. 세로로 긴 사진은 좌우에 공백이 남습니다. 끄면 칸을 꽉 채우되 사진이 늘어납니다. |

사진 크기는 칸의 **안쪽 여백을 뺀 크기**를 기준으로 계산합니다.
삽입할 때마다 진행 기록에 계산값과 실제 적용값이 남습니다.

```
삽입 1: IMG_001.jpg — 칸 21x18mm, 요청 21x18mm, 적용 21x18mm
```

## 4. 문제가 생기면

**진행 기록 패널**에 모든 동작이 남습니다. 오류가 나면 exe 옆에 `error_log.txt` 가 생깁니다.
문의하실 때 이 내용을 함께 보내주시면 원인을 찾기 쉽습니다.

### 자주 생기는 문제

**사진을 넣을 때마다 확인 창이 뜸**
보안 모듈이 등록되지 않은 상태입니다. 아래 5번을 참고하세요.

**선택한 칸이 1개로만 잡힘**
[진단] → [선택 영역 확인] 을 눌러 `SetCurFieldName(option=1)` 항목의 "이름 붙은 칸" 개수를 확인해 주세요.

**연결했는데 빈 문서가 열림**
프로그램이 새 한글 인스턴스에 붙은 경우입니다. 진행 기록에 `[주의]` 로 표시됩니다.
**[문서 열기]** 로 작업할 문서를 직접 지정하시거나, 한글을 모두 종료한 뒤 다시 시도해 주세요.

**되돌리기(Ctrl+Z)가 안 됨**
저장되지 않은 새 문서에서는 한글이 되돌리기를 받아주지 않습니다. 작업 전에 문서를 한 번 저장해 주세요.

### 진단 기능

| 버튼 | 용도 |
|---|---|
| 선택 영역 확인 | 선택한 칸이 몇 개로 읽히는지, 관련 API가 어떤 값을 주는지 |
| 커서 위치 확인 | 프로그램이 보는 한글 창이 실제 작업 창과 같은지 |
| 칸 크기 확인 | 칸 크기를 어디서 어떻게 읽고 있는지 |

## 5. 보안 모듈 등록 (한 번만)

등록하지 않으면 사진을 넣을 때마다 *"다른 프로그램이 문서에 접근하려고 합니다"* 창이 뜹니다.

1. `FilePathCheckerModule.dll` 을 원하는 폴더에 둡니다.
2. `Win + R` → `regedit`
3. `HKEY_CURRENT_USER\Software\HNC\HwpAutomation\Modules` 로 이동
   (경로가 없으면 키를 직접 만듭니다)
4. 새 **문자열 값** 생성
   - 이름: `FilePathChecker`
   - 값: dll 의 전체 경로

## 7. 구현 메모

한글 자동화 API에서 **드래그로 선택한 셀 블록을 읽는 방법**을 찾는 데 대부분의 시간을 썼습니다.
아래는 시도했다가 실패한 것들입니다. 같은 문제를 겪는 분께 참고가 되기를 바랍니다.

| 시도 | 결과 |
|---|---|
| `GetSelectedPos` / `GetSelectedPosBySet` | 셀 블록에서 `False` 반환 |
| `GetTextFile("HWPML2X", "saveblock:true")` | 블록이 아닌 표 전체 반환 |
| `KeyIndicator` | 커서 칸 주소만, 범위 정보 없음 |
| `TableIsSelectedCell` | 공식 속성 목록에 존재하지 않음 |

**해결은 `SetCurFieldName` 의 option 값이었습니다.**
공식 매뉴얼의 `HwpFieldOption` 상수 중 `hwpFieldCell = 1` 을 넘겨야
셀 블록 **전체**에 필드명이 붙습니다. `0` 을 넘기면 커서가 있는 칸 하나에만 붙습니다.

```python
hwp.SetCurFieldName(name, 1, "", "")   # 선택된 모든 칸에 이름이 붙는다
count = hwp.GetFieldList(1, 0)         # 개수 확인
hwp.MoveToField(f"{name}{{{{0}}}}")    # 인덱스로 하나씩 방문
```

각 칸을 방문하며 `GetPos()` 로 칸 번호를 모은 뒤 필드명을 지웁니다.
범위를 추측하지 않으므로 떨어진 선택도 정확합니다.

### 그 밖에 알아낸 것

- `SelectionMode` 는 `0x0F` 로 마스크해서 판단해야 합니다. F3/F4 블록은 `0x10` 이 OR 마스크되어 옵니다. (`19 & 15 = 3` → 셀 블록)
- `CellShape` 는 **표**의 속성입니다. 셀 속성은 그 안의 `Cell` 아이템에 있습니다.
- `InsertPicture` 의 `sizeoption` 은 넘긴 width/height 를 무시하고 한글이 스스로 계산합니다. 크기를 정확히 지정하려면 삽입 후 개체의 `Properties` 를 직접 수정해야 합니다.
- `ShapeObjDialog` 로 크기를 바꾸면 지정하지 않은 속성까지 기본값으로 함께 적용됩니다.
